# Biblioteca Digital

Sistema web desenvolvido com Python e Django para auxiliar no gerenciamento de uma biblioteca.

## Sobre o projeto

A Biblioteca Digital tem como objetivo facilitar o gerenciamento de livros, clientes e empréstimos, permitindo controlar a disponibilidade dos livros e consultar as informações do acervo.

## Funcionalidades

### Funcionário
- Cadastrar livros
- Editar livros
- Excluir livros
- Cadastrar clientes
- Editar clientes
- Registrar empréstimos
- Registrar devoluções
- Gerar relatório de empréstimos

### Cliente
- Pesquisar livros
- Consultar informações dos livros
- Verificar a disponibilidade dos livros

## Tecnologias

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## API externa

O projeto utiliza a Open Library API como fonte externa para consulta de informações bibliográficas de livros.
